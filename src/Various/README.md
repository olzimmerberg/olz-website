# `Various/`: Einmalige Seiten

Sammelort für einzelne Seiten, die zu keiner eigenen Domäne gehören (Datenschutz,
Angebot, Für Einsteiger, Email-Reaktion, Strava-Redirect, …). Anders als
[`src/Common`](../Common/) enthält dieser Ordner also keine wiederverwendbaren
Bausteine, sondern die "lange Liste" an Spezial-Seiten.
